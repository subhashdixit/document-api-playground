Source, concepts and operating guide ↗

Local demo store · Browser-only JSON documents are not MongoDB. Server mode requires your own deployed backend and access token; neither is embedded in this page.

Connect your own MongoDB API

Enter the endpoint of a backend you control. The token is sent only to that endpoint, is kept in tab memory and is not stored. These owner-level CRUD credentials can edit/delete that configured collection; use a dedicated demonstration collection.

1 · Create or edit JSON

No Mongo operators, dotted keys or prototype keys. Nested plain JSON is supported.

2 · Inspect documents

How this works · scope and limitations

Local mode validates documents and saves a browser JSON collection. Server mode uses a separate authenticated Flask/PyMongo backend with fixed database/collection configuration. The backend receives no raw Mongo query operators from the browser. Export local backups before clearing browser data.
